# FIRE-COMMAND STUDIO 웹 전용판

루트 web/는 설치 프로그램 없이 웹주소로 사용하는 새 웹 전용판이다. 기존 apps/web + apps/api와 Windows 설치판은 보존한다. 원본 plan.md는 변경하지 않는다.

## 확정된 요구

- 진행자 PC 한 대 + 대형 공개화면 + 참가자 구두 토론 + 진행자 대리 입력.
- 훈련용 워터마크, 실제/가상 대상물·자료 출처·정확도, AI 기본 OFF, 실제 지휘망 미연결 유지.
- 제작/역할·숙지/발행·사건/보고·조치/인계/평가·AAR/기록·재생/백업복구의 기존 도메인 계약과 합성 예시부터 대조한다.
- 공개화면은 미래 사건·정답·개인평가를 받지 않는다. 브라우저 내부 운영을 기관 서버의 사용자/기관 격리 검증과 동일하다고 표현하지 않는다.
- TypeScript + React + Three.js 화면과 기존 공통 계약을 재사용하고, 저장/명령/공개 투영을 런타임 어댑터로 분리한다.

## 확인 중인 필수 결정

1. GitHub Pages에서 실행하는 브라우저 전용판: IndexedDB 등 브라우저 저장과 파일 백업/복원을 사용한다. 운영체제 도구/실제 AV·비밀키 외부 API/기관 서버 인증을 브라우저의 숨김 UI로 대체하지 않는다.
2. 기존 기능과 서버 권한을 유지하는 웹서버 방식: 사용자는 브라우저만 사용하고 별도 웹서버가 권한/API/영구 저장을 처리한다. 서버 주소·운영 환경은 승인된 값이 필요하다.

이 선택은 사용자에게 질문했으며 종속되는 저장/배포 구조는 답변 전에 임의 확정하지 않는다. 현재 폴더 생성과 공유 계약 준비는 웹판 실행/배포 완료를 의미하지 않는다. 구현·검증은 docs/WEB_DEVELOPMENT_PLAN.md와 WORK_LOG/REQUIREMENTS/TEST_PLAN에서 추적한다.

## 공통 화면 개발 기반

루트에서 npm ci 후 npm run typecheck --workspace web 및 npm run build --workspace web를 실행한다. npm run dev --workspace web는8015번 개발 UI이며, API/WS 프록시8016은 별도의 합성 검증 서버를 위한 개발 설정이다. 기존8010 사용자 실행본/데이터를 시험 대상으로 쓰지 않는다. 현재 공통 화면을 재사용하는 개발 기반이며 브라우저 저장 어댑터나 운영 서버 배포가 완료됐다는 뜻이 아니다.

합성 API 검증 서버의 ALLOWED_ORIGINS에는 http://127.0.0.1:8015만 명시한다. 기존 서버의 전체 허용 목록을 넓히거나 출처 검증을 끄지 않는다. 새 개발 포트를 허용하지 않은 최초 두 브라우저 시험은403으로 실패했으며 설정을 명시한 뒤 재검증했다. 전체 웹판의 기능·영구 저장·공개 배포 완료 증거와 구분한다.

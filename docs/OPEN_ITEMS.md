# 승인·실증·후속 작업

## 현재 브라우저 검증 상태

사용자의 별도 백그라운드 검증 지시로 **Chrome 연결 문제를 기다릴 필요 없이 독립 Chromium/Firefox 검증을 완료했다**. 기존 Chrome 프로필·탭은 사용하지 않았다. 아래 Chrome 관련 질문/거절은 과거 경위이며 현재 로컬 검증의 미해결 조건이 아니다. 추가 Chrome 설정은 필요 없다. 실제 기관 자료·키·승인·시범훈련 항목은 계속 남아 있다.

## 사용자에게 질문한 항목

1. 기관 PostgreSQL/서버 환경과 실제 시범훈련 담당자: 상세 정보 미제공. plan §20 기본값으로 로컬 합성 개발을 진행했다.
2. 브라우저 호스트 미연결·Chrome 접근 승인 거절 이후 로컬 Playwright 실행 허용: 이후 사용자 지시로 해소했다. 현재 독립 headless 두 엔진 검증을 사용한다.
3. 과거 Chrome 설치/승인 요청 재시도는 동일 승인 거절이었다. 실제 확장 설치/연결은 확인되지 않았으나 현재 검증의 차단 조건이 아니다.
4. 과거 연결 브라우저0개·호스트 부재 재시도 기록을 WORK_LOG에 보존했다. 로컬 설정을 변경하지 않았으며 현재는 추가 Chrome 설정을 요구하지 않는다.
5. ‘항상 허용’ 후에도 Chrome 연결은 실패했으나 이후 백그라운드 브라우저 검증 지시로 별도 Playwright 설치/실행을 허용받았다. 기존 프로필/탭을 사용하지 않는다.
6. 기관 승인 악성코드 검사기·IFC 오프라인 호스트는 질문 후 답변 대기다. 기본 운영 플래그는 비활성이고 합성 응답을 실제 AV로 표시하지 않는다.

키·비밀번호·실명명부·도면을 이 문서나 채팅/Git에 기입하지 않는다. 승인된 환경변수·기관 저장소에서 설정한다.

## 기관 확인이 필요한 것

- 실제 법령 별표·기관 SOP·편성·지휘/보고선·통제단 전환·대체 권한의 검수자와 승인 기록
- 기준 PC/GPU/브라우저/1080p 프로젝터·기관 LAN, 약 10명 실제 참가자·진행자·평가관의 시범훈련 일정
- 실제 대상물·사진·도면/BIM·위치·공개범위·촬영/가공 이용권 및 보안 승인
- 카카오 JavaScript 키·도메인·약관·외부 인터넷, 공공 API의 최신 명세·실키 응답·정정 정책
- 운영 DB·TLS·계정/SSO·보유기간·백업복구·접근/반출 로그 정책

## 후속 구현·검증 (미완료를 숨기지 않음)

- 공공 데이터 HTTP·정규화·불변 수집/검토/반영과 합성 장애/권한 시험은 구현했다. **실키 응답·기관별 소방용수 데이터셋/컬럼·이용권·최신성 검수는 미실행**이다. 설정/계약은 `PUBLIC_DATA.md` 참조.
- 승인 모델 저장/조회·GLTFLoader·층/객체 매핑·사진 한 면 색상맵/참고 화면·오프라인 IFC CLI는 구현했다. 실제 허가 모델/사진·실측 물성·단위/정확도 검수는 미실행이다. 설정/제한은 ASSET_PIPELINE 참조.
- 로컬 clamd 어댑터와 fail-closed 격리는 구현했으며 실제 검사기/오프라인 네트워크 정책 검증은 대기다. 기관 SSO·PostgreSQL·다중 인스턴스 운영 검증은 별도다.
- 영상은 고정 도구의 실제 합성 변환·서버 격리/검토/사건 cue·공개 전/역할/되돌림 차단과 업로드 미리보기·사건 편집·동기 재생/AAR를 구현했다. 서버 왕복 시계 보정·상세 생성기/환경/예산 보완 후 Chromium/Firefox 각13개 전체 흐름이 통과했다(MEDIA_TIMELINE). 실제 AV·영상 권리/익명화·호스트 보안·실시간 중계 필요 여부는 답변/검증 대기다. FDS와 승인 AI 등 M6는 계획상 출시 후 선택 확장이다.
- 승인된 AI 공급자·생성물 스키마·기밀 필터·사람 승인 경로. 현재는 모든 AI 요청이 비활성으로 거절됨
- 독립 headless 화면·카메라/반응형·인쇄/PDF는 검증했다. 기관 기준장비의 지속24fps/초기 전체10초·실제 LAN·회의실 후열 가독성 실증은 남아 있다.

이 항목들은 로컬 합성 MVP 자동시험을 통과했다는 사실로 완료 처리하지 않는다. 기관 정규 출시의 필수 AC와 전문가·보안·실사용 검수가 끝날 때까지 출시 보류 상태다.

최종 로컬/CI 보완 후에도 기관 검수·실제 시범훈련 필수 입력이3개 연속 목표 턴에서 미제공이다. 자세한 재확인 근거는 docs/evidence/external-blocker-audit-20261117.json에 기록했다. 실제 검수자/담당 역할·일정과 승인된 환경/자료가 확인되면 현 고정본에서 실제 시험→결함 수정→회귀→수용 기록으로 이어간다. 로컬 자동시험을 실제 승인으로 대체하지 않는다.


2026-11-18 U30: 방식 선택은 웹서버+Windows 로컬로 확정됐고 JSON 설정/두 트랙 패키지/실제 업그레이드·공개v0.2/Pages 검증을 완료했다. 실제 공개 웹서버·호스팅/도메인 질문의 답변은 아직 없으며, 배포 가능한 ZIP/HTTPS Compose를 먼저 제공했다. 서버 지정 후 DNS/TLS/기관 계정·보존정책과 실제 환경 검증을 이어간다. 새 유료 서비스·공개 서버 주소를 임의 생성하지 않았다. 기관 정규 수용 조건은 그대로다.

## SCREEN 전국 실제 건물 연계(U32)

사용할 실제3D/실사 데이터 공급자·커버리지·사용권/키 또는 기관 보유 GLB/사진·좌표 자료가 미제공이다. 관련 질문은 답변 대기이며 전국 자동 지도 스트리밍 연계는 미구현이다. 승인 자료 파일 연결·가상 현장·사전 배치/JSON·훈련 시계/메시지·밝은 UI 검증과 혼동하지 않는다. 실제 AV·기관 전문가·기준 GPU/후열 판독·약10명 회의실 시험도 필요하다. 새 유료 계정/서버·임의 수집·로드뷰 텍스처를 사용하지 않는다.

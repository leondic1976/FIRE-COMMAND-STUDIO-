# 웹서버·Windows 로컬 투트랙 구현 계약

2026-11-18 U30 확정: 웹서버 방식과 Windows 로컬 방식을 함께 제공하고 설정은 JSON으로 저장한다. 기존 배포 방식 선택 질문은 해소됐다. 원본 plan.md는 변경하지 않는다.

## 데이터 계약

- 실행 설정: 사용자/서버의 비공개 데이터 폴더 settings.json, schema_version=1. 허용된 승인/연계 설정만 읽고 실행 시작 시 고정한다. 기존 settings.env는 최초1회 읽어 JSON으로 마이그레이션하되 원본은 보존한다. 실제 키가 있는 실행 설정은 프론트엔드·공개 Git·검증 증거·훈련 설정 다운로드에 포함하지 않는다.
- 훈련 설정: FIRE_COMMAND_STUDIO_CONFIGURATION 형식/version1 JSON. 정의·조직/역할·배치·장면·사건을 내보내고 체크섬/크기/중복 키/형식/참조를 검증한 뒤 새 편집본으로 가져온다. 숙지·구두 확인·검수/발행·기관 승인·자산 승인 상태를 자동 승계하지 않는다. 가져오기는 기존 자료를 덮어쓰지 않고 기관/역할 권한·멱등키를 적용한다.
- 실행 중 사건/조치/평가/이력은 기존 DB 원자 저장을 유지한다. JSON 설정 파일은 전체 훈련 DB 백업의 대체물이 아니다. 기존 DB schema2는 유지하며 파일 버전1의 읽기/마이그레이션·백업/복원 경계를 문서화한다.

## 구현

1. 공통 JSON 실행 설정 저장/엄격 검증/원자 교체/구형 env 마이그레이션과 Windows 로컬 연결.
2. 권한 있는 훈련 JSON 미리보기·내보내기·새 편집본 가져오기 및 두 트랙 공통 UI.
3. web/dist를 같은 출처의 FastAPI/WS와 함께 제공하는 웹서버 실행기, production HTTPS/Origin·계정·영구 저장·공개 키 투영과 배포 패키지.
4. 기존 Windows 설치형을 새 JSON 설정/기능으로 재빌드·실제 설치/기록 보존·브라우저 회귀/백업복원 검증.
5. 웹서버·로컬 각각 정상/오류/기관·역할 격리/공개 유출 금지/재시작·설정 파일 복구·두 브라우저 실제 흐름과 CI를 확인하고 기록한다.

## 완료 및 외부 경계

웹서버·로컬 구현과 기관 정규 출시 승인은 구분한다. 실제 기관 SOP/키/AV/모델 이용권·약10명 회의실 실증을 만들어내지 않는다. 웹을 실제 공개할 서버/호스팅·도메인은 사용자에게 별도 질문했으며 구현/배포 가능한 패키지/검증은 답변과 독립적으로 완료한다. 새 유료 계정/실제 공개 서버 운영을 질문만으로 생성하지 않는다. GitHub Pages는 공개 안내/설치 다운로드이며 Python 운영 서버와 구분한다.

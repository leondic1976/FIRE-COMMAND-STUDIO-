# 출처·권리·정확도

## 현재 포함된 자료

| 자료 | 출처 | 이용·정확도 상태 |
|---|---|---|
| 기본 역할·임무 요약 | 사용자 제공 plan.md §2 및 공개 법령 참조 | 훈련용 요약, 기관 SOP 검수 전 |
| 제16조제3항 부서 매핑 | [국가법령정보센터](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=63283) | 2026-11-16 재열람, 2026-07-01 시행 표시 확인 |
| 건물·도로·차량·소화전·장면 재질 | 프로젝트의 절차 생성 코드와 합성 예제 | 가상 외관·위치·배치, 실측/공학 예측 아님 |
| 인원·숙지·사건·관찰 예제 | 가명 ID와 자동시험용 합성 응답 | 실제 직원·시설·사고·기관 승인과 무관 |
| UI 아이콘 | lucide-react 패키지 | 패키지 라이선스에 따른 아이콘, 기관 공식 로고 아님 |

기본 법령 요약은 공식 별표 전체 및 기관 내부 SOP의 전문가 재검수를 대체하지 않는다. 법정 지휘대장과 실제 기관 통제단장 관계를 임의로 확정하지 않는다.

## 선택적 공식 SDK

[Kakao Maps 공식 가이드](https://apis.map.kakao.com/web/guide/)와 [로드뷰 예제](https://apis.map.kakao.com/web/sample/basicRoadview/)를 기준으로 SDK 안의 표시·마커·윤곽·위치 연동만 준비했다. 실제 키·등록 도메인·권리·서비스 응답은 검증되지 않았다.

승인 플래그와 공개 JavaScript 키가 없으면 SDK 스크립트도 요청하지 않는다. 실제/혼합 모드에서 사용자가 지도/거리뷰를 선택했을 때만 표시를 시도한다. 지도 로고·출처를 숨기거나 픽셀을 저장·복제하지 않는다. 로드뷰의 촬영 시점은 위젯 제공 정보로 확인하며 훈련시계·대상물 기준일과 구분한다.

## 아직 제공받지 않은 자료

건축물대장·기상·소방용수 실응답, 실제 도면·IFC·GLB·사진, 촬영·재가공 이용권, 현장 대조·좌표 보정, 검증된 FDS 데이터는 없다. 법령 전체 별표·기관 SOP 전문의 최종 검수자도 미지정이다. 해당 자료를 실제 검증됨으로 표시하지 않는다.

건축물대장의 행정 속성을 실제 외관·실내 도면으로 자동 간주하지 않는다. 권리 미확인·제한 자료는 발행 게이트에서 차단하고, 실제 대상물은 출처·검수자·비합성 분류를 요구한다.

## 공공자료 구현·시험 구분

2026-11-17 건축물대장·기상·기관 지정 ODcloud 용수시설 HTTP 어댑터와 불변 수집/검토/초안 반영 경로를 구현했다. 공급자별 공식 명세, 키를 보관하는 위치, 항목 기준일/관측시각·결측·이용권 확인과 실패 대안은 [PUBLIC_DATA.md](PUBLIC_DATA.md)에 기록한다. 합성 HTTP 응답 시험은 실제 기관자료 수집이나 권리 승인으로 간주하지 않는다. 실키·현장 대조는 여전히 미실행이다.

## 관련 기술 출처

- [Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html): 검토 후 해시 고정 GLB 로딩 기준. 합성 모델 등록/렌더링은 두 엔진에서 검증했으며 실제 시설 정확도 승인은 아님.
- [FEMA HSEEP](https://www.fema.gov/emergency-managers/national-preparedness/exercises/hseep): 계획서의 토론훈련·AAR/IP 참고 자료. 국내 법령에 직접 강제 적용되는 기준으로 표시하지 않음.
- [GitHub 공식 checkout](https://github.com/actions/checkout), [setup-node](https://github.com/actions/setup-node), [setup-python](https://github.com/actions/setup-python): 현재 공식 사용 예제의 v7을 확인해 CI 정의에 반영. 원격 CI 실행은 미실행.

## 모델·사진·IFC 구현 자료

추가3층 모델·창호·외벽 색상표·참고사진·IFC는 tests/asset_fixtures.py에서 생성한 합성 자료다. 실제 시설/사진/기관 승인과 무관하다. 입력 원천·제작자·이용범위·기준일·공개범위·검토 이력과 원본/정규화 해시를 비공개 DB에 보존하고 실행 스냅샷과 AAR 출처에 연결한다. 사진 메타데이터를 제거해도 얼굴·차량번호·표지판의 육안 익명화가 완료됐다는 뜻은 아니다. 실제 입력 전 사람의 개인정보/이용권 검토가 필요하다.

IfcConvert 공식 고정0.8.5의 합성 변환·자원 제한은 검증했으나 제공자 변환 기록은 기관 승인이나 실내 실측 검증이 아니다. 도구 출처/ZIP/전체 파일 해시와 운영 제한은 ASSET_PIPELINE, 고지/재배포 조건은 DEPENDENCIES에서 추적한다.

# Windows 설치형 배포 계약

사용자 최종 선택(2026-11-17): 대형 화면을 보고 구두로 토론하며 진행자 한 명이 PC로 운영한다. 원래 기능을 유지하기 위해 Windows 로컬 설치 프로그램을 별도로 내려받도록 한다. 정적호스팅에는 다운로드·설치/운영 안내를 게시한다. 여러 PC 접속·브라우저 전용 서버리스 전환은 필수가 아니다. 원본 plan.md는 변경하지 않고 최신 지시 U26을 현재 배포 구조에 적용한다.

## 제공물과 경계

- 검증된 FastAPI/SQLite·React/Three.js·역할/숙지/인계/사건·AAR를 유지한 독립 Windows64비트 설치 프로그램. 사용자 PC에 Python/Node 설치를 요구하지 않는다.
- 설치 앱은127.0.0.1에만 바인딩하며 기본 브라우저에서 UI를 연다. 시작/종료를 제어할 작은 실행 창과 바로가기를 제공한다. 같은 PC의 별도 공개 화면을 프로젝터로 표시한다.
- 실행 파일/정적 자원은 설치 폴더, DB·설정·백업은 사용자별 LocalAppData 하위에 분리한다. 기존 개발 runtime/DB/쿠키/캡처를 포함하지 않는다.
- 재실행/업데이트/제거 시 사용자 훈련 기록과 백업을 임의 삭제하지 않는다. 한 저장소에 중복 인스턴스를 만들지 않고 포트 충돌은 안전하게 처리한다.
- AI OFF·실제 지휘망 미연결·워터마크·공개/비공개 투영·권리/검사 격리·기존 도메인 게이트를 유지한다. 실제 기관 승인·숙지/실제 AV 검사를 만들어내지 않는다.
- 승인 AV/IFC/영상 도구의 기존 오프라인 설정·사용권 조건은 유지한다. 미승인 바이너리/실키/환경변수·외부 세션을 설치 프로그램에 묶지 않는다.
- 정적 안내 사이트는 설치본 버전/다운로드 URL·크기·SHA256·전자서명 상태와 단일 PC 사용 순서를 표시한다. 다운로드·설치형 실행을 정적 사이트에서 직접 수행한 기능으로 오인시키지 않는다.

## 수용 검증

1. 독립 패키지를 깨끗한 사용자 데이터 경로에서 실행해 건강상태·한글 UI·3D 자원과 전체 기본 API를 확인한다.
2. 실제 설치/실행/종료/재실행·중복 실행/포트 점유를 시험하고 기록 보존·복구 상태를 확인한다.
3. 기존 역할/숙지·발행·사건10개·보고·인계·평가/AAR의 브라우저 흐름을 패키지 실행본에서 확인한다. 공개 화면의 미래 사건/정답/개인평가 유출 금지와 백업복구도 확인한다.
4. 설치본의 허용 파일 목록·의존성/라이선스·기본 설정을 대조하고 DB/키/쿠키/실명명부/개발 임시자료가 없는지 검사한다. 실제 전자서명/AV 검사 여부는 사실대로 표시한다.
5. 업데이트/제거는 격리된 QA 설치 경로에서 실제 수행하며 사용자 저장소를 보존한다. 미실행 OS/백신 환경을 통과로 기록하지 않는다.
6. GitHub Release에 설치 프로그램과 체크섬을 게시하고 정적 사이트의 실제 다운로드 링크/해시·반응형·한국어·설치 안내를 확인한다. 기관 정규 출시 승인과 구분한다.

브라우저 전용 WebAssembly 검토는 U26으로 중단했다. 해당 의존성/미완성 소스를 제품에 넣지 않으며, 조사한 배포본의 구형 이미지 패키지도 포함하지 않는다. 설치형 구현과 독립 패키지 검증을 마쳤으며 실제 설치/브라우저·재설치/제거 시험과 게시 증거는 아래에 유지한다.

고급 승인 설정은 사용자 데이터 폴더의 settings.env에만 입력한다. 이 폴더는 실행 창의 기록·백업 폴더 버튼으로 연다. 공개 지도 JS 키는 승인 후 재시작하면 적용하고, 공공 API 비밀키는 로컬 서버만 읽는다. 승인된 IFC 변환은 `FIRECommandStudio.exe --convert-ifc 입력.ifc --output 새출력.glb --headless --no-browser`로 HTTP 서비스를 시작하지 않고 수행한다. 도구/AV/권리 승인은 기존 ASSET_PIPELINE을 따른다.

## 설치·운영 방법

1. [릴리스](https://github.com/leondic1976/FIRE-COMMAND-STUDIO-/releases/tag/v0.1.0)에서 `FIRE-Command-Studio-Setup-0.1.0-x64.exe`를 내려받는다. 게시 SHA256과 파일을 대조할 수 있다. 설치본은 전자서명되지 않았다.
2. 설치 프로그램을 실행한다. 사용자별 설치이며 관리자 권한과 별도 Python/Node 설치가 필요하지 않다. 기본 설치 폴더는 `%LOCALAPPDATA%\Programs\FIRECommandStudio`다.
3. 시작 메뉴의 FIRE-COMMAND STUDIO를 실행한다. 제어 창의 **훈련 스튜디오 열기**에서 기본 브라우저를 연다. 기본 주소는 `http://127.0.0.1:8765`이며 다른 프로그램이 점유하면 빈 포트를 사용한다. 제어 창에서 현재 앱을 연다.
4. 진행자 한 명이 조작하고 **공용화면**을 프로젝터로 옮긴다. 참가자는 화면을 보고 구두로 토론하며 진행자가 대리 입력한다. 공용화면에는 별도의 서버 공개 투영을 사용한다.
5. **전체 훈련 백업 저장**으로 DB를 저장한다. 함께 생성되는 `.manifest.json`을 같은 위치에 함께 보관한다. **백업에서 복원**은 현재 상태를 자동 백업한 뒤 검증된 백업으로 교체하고 재시작한다. 내보낸 AAR만으로 전체 DB를 복구하지는 않는다.
6. 제어 창의 **스튜디오 종료**로 마친다. 설정의 앱 제거는 설치 파일을 제거하며 사용자 데이터는 유지한다. 다시 설치하면 같은 기본 데이터 폴더를 읽는다. 다른 Windows 계정은 별도 데이터 폴더를 사용한다.

최소 설치 대상은 Windows10 이상 x64다. 실제 수용 시험 OS는 Windows11 Pro 64비트/10.0.26300이다. Windows10 및 다른 PC의 설치/화면 성능은 시험하지 않았다. 외부 자료·AV·변환 도구 승인은 기본 비활성이며 설치본만으로 기관 승인 외부 서비스를 활성화하지 않는다.

# 가상 대상물 생성기 추가 계약

2026-11-17 plan §7.5/7.6/8.1, AC10/12/18/19/21/26/30/35의 세부 대조에서 확인했다. 현재 건물 외형/층수/용도/출입구/윤곽/위치/회전과 장면 JSON 편집은 제공하지만, 지붕/창호/마감·층별 윤곽·내부 구역의 GUI 저작을 입증하지 못했다. 기존 AC10의 기본 편집 시험으로 아래 범위를 완료 처리하지 않는다. 원본 계획은 변경하지 않는다.

## 기본 자료 계약

- Building의 이전 자료는 기본값으로 읽는다. 지붕 FLAT/GABLE/SHED, 창호 REGULAR/NONE, 마감 CONCRETE/BRICK/METAL/GLASS, 지하층 수, 층별 윤곽을 선택적으로 저장한다. 모두 합성 기하/PBR 속성이며 실제 건축 표준·실측 물성이라고 표시하지 않는다.
- 용도 프리셋은 공장·창고·지하상가·고층아파트·다중이용시설·의료시설·학교·위험물 시설·지하차도·복합건물을 제공한다. 제안 치수는 가상 초기값이며 법적/소방 설계 기준이 아니다. 기존 작성 자료를 몰래 삭제하지 않는다.
- 내부 실·복도·계단·승강기·방화구획·피난통로·소방시설·위험물 저장구역과 연결통로는 기존 Feature ID 체계를 확장한다. 건물·층·로컬 위치·폭/깊이·방향과 연결 대상 건물을 저장한다. 같은 ID를 사건 패치/객체 선택/2D·3D·기록에서 참조한다.
- 지하는 음수 층으로 구분하며 0층은 기존 대지/건물 전체 참조로 유지한다. 건물의 지하/지상층 범위를 벗어나거나 없는 연결 건물·중복 ID/층별 윤곽은 발행 차단한다.
- 윤곽은 유한 좌표·최소 면적·비퇴화 변·자기 교차를 검사한다. 입력/장면 예산을 제한하고 과대 장면은 같은 상태의2D 대안으로 전환한다.
- 도로·주차장·용수·차량·집결지·의료자원·통제선의 이름/위치/크기/회전/초기 상태를 GUI로 편집한다. 출처 기반 참고시설은 이 경로에서 수정하지 않는다. 인접동의 주건물 기준 거리/방위는 같은 x/z 좌표로 환산한다.
- 초기 상태와 패치는 동일한 유한값/형식/안전 예산을 검사한다. smoke/fire/rain 0~4, 수치 water 0~20, wind 0~200, radius 0~2000, casualties 0~100000 정수, closed/warning/power 불리언, water 상태문자/status/communication 1~100자다. 이는 합성 시각효과/메모리의 입력 예산이며 실제 물리량이나 법정 기준이 아니다. 렌더러도 연기/화염/침수/반경을 방어 제한한다.
- 실제 시설/허가 자산은 기존 출처·권리·정확도·서버 권한 규칙을 따른다. 단순한 내부 도식 생성으로 interior_verified를 켜거나 기관 승인을 합성하지 않는다.

## GUI와 표시

선택한 건물의 프리셋/외관, 층별 윤곽과 내부 요소를 폼·평면도에서 편집한다. 생성/복사/삭제는 초안 변경이며 저장/품질검사/발행·실행본 동결 절차를 따른다. 기존 사건이 참조하는 요소의 삭제는 경고하고 참조를 수정할 때까지 발행을 차단한다. 인접동 복제는 고유 ID를 생성하며 원본 사건/자산 승인·내부 요소 ID를 공유하지 않는다.

층 선택/절개 표시로 내부 요소를 확인하고2D 대안에도 ID·이름·층·상태를 제공한다. 도식·절개·재질을 실제 건축/피난 성능이나 공학 예측으로 표현하지 않는다. 프로시저 생성 기하의 GLB와 장면 JSON/출처 메타데이터를 고정해 재사용하는 내보내기 경로도 검증 대상이다. 허가 자산의 재배포 권리를 자동으로 부여하지 않는다.

## 완료 증거

계약 정상/오류·구버전 호환·권한/공용 투영·발행/재생/복구 시험, 순수 좌표/기하 규칙, 타입/빌드, 두 실제 브라우저의 프리셋→윤곽/내부 요소→저장/재조회→3D/2D·사건 연결·내보내기를 확인한다. 미실행 항목은 통과로 기록하지 않는다. 전체 범위 감사 뒤 최종 API 고정본으로60분 시험을 수행한다.

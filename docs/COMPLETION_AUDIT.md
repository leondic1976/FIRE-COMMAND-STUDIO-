## 사전 질문과 출시 조건

기관 SOP 검수자·실제 시범훈련 담당/일정, 실키의 승인 서버 설정, 실제 모델/사진 이용권·기준 장비, 실제 AV/오프라인 호스트에 관한 질문은 답변 대기다. 기본값으로 로컬 개발을 계속하되 이 항목을 승인 완료로 취급하지 않는다. 다른 사람에게 연락하거나 GitHub/원격 배포로 승인 절차를 대신하지 않는다.

전체 목표 완료에는 필수 AC 결과, 전문가 검수, 실제 진행자1/참가자 약10/평가관1의 회의실 관찰·개선/재시험, 기관 보안/권리·운영 승인 증거가 필요하다. 각 자료를 받은 뒤 해당 실제 환경/버전에서 다시 검증한다. 시간 추정은 로컬 마무리와 기관 일정으로 나누고 총량의 근거 없는 백분율을 완료 증거로 사용하지 않는다.

현60분 시험은 완료됐고 소스 일치·실행시간·12접속·사건 누락/중복·연속 시퀀스·최종 장면·권한 유출 결과를 검사해 증거를 발행했다. 외부 조건이 계속 미제공이어도 완료로 표시하지 않는다.

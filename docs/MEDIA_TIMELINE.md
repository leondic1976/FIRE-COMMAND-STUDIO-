# 승인 녹화 영상·사건 타임라인 계약

2026-11-17 원본 plan §6.2/7.2/8.4/9.1 및 AC19/27/30 재감사에서 확인한 미구현 요구다. 이 문서는 먼저 작성하는 구현 계약이며, 실행 결과는 TEST_PLAN에 추가하기 전까지 완료/통과를 뜻하지 않는다. 실시간 중계 필수 여부는 질문 중이다. 공통 기반으로 승인 녹화 파일·사건 연결부터 진행하며 임의 URL/실제 드론·지휘망에 연결하지 않는다.

## 자료와 검사

기존 기관별 자산 저장/AV/권리 검토에 VIDEO를 추가한다. 입력은 크기가 제한된 MP4/WebM 파일, 원천·제작/촬영자·촬영/자료시각·대조범위·이용범위·보안분류다. AV 원본 CLEAN 이후에만 고정 도구의 제한 작업 프로세스로 검사/재인코딩하며, 정규화 영상도 AV 검사를 거친다. 키/임의 인수/외부 URL을 도구로 전달하지 않는다.

도구와 실제 검사기 미설정/오류는 격리하며 정적 URL/파일 경로를 제공하지 않는다. 해시로 고정한 ffprobe/ffmpeg·입력/출력 크기·duration/해상도/fps·프로세스/CPU/벽시계/메모리/환경·개인 전용 임시 디렉터리 제한을 적용한다. 프로토콜/디먹서 허용목록, MOV 외부 data reference 차단, 첫 영상/허용 음성 트랙만 재인코딩하고 첨부/자막/장/개인 메타데이터는 제거한다. 저작권 표시는 별도 매니페스트에 보존한다. Job 자체는 네트워크/파일시스템 샌드박스가 아니므로 실제 운영의 보안 격리는 기관 검증 대상이다.

기본 구현 예산은 파일15MiB, 길이180초, 입력4096px·60fps 이하, 정규화960×540 이내·20fps·WebM VP8/Opus다. 오류/범위 초과는 구체적인 사유와 오프라인 클립/수동 대안을 제공하며 임의 잘라내기를 성공으로 표시하지 않는다. 기본 음소거와 촬영시각/훈련시각 구분을 유지한다.

입력보다 해상도를 키우지 않는다. Opus 부호화 패딩에 의한 정규화 컨테이너 길이 증가는 최대0.25초만 허용하고 실제 길이를 매니페스트에 기록한다. 픽셀 안의 얼굴/번호판이나 음성을 자동 익명화했다고 주장하지 않는다.

## 사건 연결과 공개 경계

훈련 자산 연결은 `purpose=VIDEO`, 기존 building_id/공개범위·권리 확인·전후 검토 이력을 사용한다. 사건은 선택적 media cue 목록으로 연결 자산ID·동일 feature_id·클립 시작/끝을 지정한다. 범위/참조/권리·공개 가능 여부를 발행 전 검사한다. 일반 편집으로 자산 승인을 위조할 수 없다.

공개 전에는 영상의 ID·라벨·출처·원본/정규화 해시·길이와 바이트 모두 참가자/공용 응답에서 제외한다. 공개 메시지의 cue는 사건 시퀀스·공개 훈련시각과 함께 원자 저장한다. 진행자/평가관 전체 스냅샷과 별도로, 공동화면/개인 권한으로 볼 수 있는 메시지가 참조하는 영상만 DTO/콘텐츠 경로에서 제공한다. STAFF 영상의 공용 사건 연결은 발행 차단한다. 공동화면 전용 바이트 경로는 진행자 쿠키에도 공개 투영을 강제한다. 되돌린 사건·재생의 미래 사건·인계 이전 비권한 메시지는 같은 경계로 처리한다.

현재 두 단계 공개 정책에서 STAFF/INTERNAL 영상은 제작/평가 검토 전용이므로 참가자 사건 연결을 차단한다. PUBLIC 연결은 사건의 PUBLIC/PRIVATE 수신권한을 다시 적용하는 ‘공개 가능’ 상태이며 파일 전체를 즉시 공용으로 발행한다는 뜻이 아니다. 기관 내부 영상의 참가자별 공개는 실제 보안정책 확인 없이 허용하지 않는다.

## 구현 진행과 도구 근거

고정 FFmpeg9.0.2의 합성 MP4→WebM 실제 변환·메타데이터 제거·원크기 유지·계약/게이트9건, 영상 수집/격리·사건 원자 연결·공개 전 메타데이터/바이트/WS 차단·PRIVATE 수신자 허용/타인 거절·되돌림/복제3건을 먼저 시험했다. 통합3건은 명시적인 합성 AV/처리 프로토콜을 주입하며 실제 AV가 아니다. 이후 사건 편집·미리보기·동기 재생·AAR를 구현했다. 시계 보정 후 전체209·웹22·Chromium 실제 합성 영상 흐름1건38.710초 통과, Firefox 전체 회귀는 진행 중이다. 재접속 뒤 한 표본의 보정 오차0.006946초는 로컬 한정이며 기관 LAN 성능으로 일반화하지 않는다. 전체 결과는 TEST_PLAN을 따른다.

`python scripts/prepare_media_tool.py runtime/tools/ffmpeg-9.0.2`는 [FFmpeg 공식 다운로드 안내](https://ffmpeg.org/download.html)에 연결된 [Gyan Windows 배포](https://www.gyan.dev/ffmpeg/builds/)의 고정9.0.2 ZIP만 사용한다. [고정 ZIP SHA256](https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-9.0.2-essentials_build.zip.sha256)은 `60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`, ffmpeg/ffprobe 전체 파일 매니페스트 SHA256은 `2ee159e584c91aa77a0acab7d46968f7de5bed7f0d3b5526332e03b476848dce`다. 도구/라이선스 원본 ZIP은 runtime에 보존하고 재배포하지 않았다. 배포본은 GPLv3 고지를 보존해야 하며 기관 재배포/운영 승인으로 간주하지 않는다.

`MEDIA_PROCESSING_APPROVED`, `MEDIA_PROCESSING_APPROVAL_REF`, `MEDIA_HOST_ISOLATION_CONFIRMED`, `MEDIA_TOOL_MANIFEST`, `MEDIA_TOOL_MANIFEST_SHA256`은 기본false/비어 있음이다. 실제 AV와 승인 호스트를 검증하기 전 운영 활성화하지 않는다. 합성 네이티브 시험은 RUN_MEDIA_TOOL_TESTS=1로 분리한다.

## 재생 동기와 이력

영상 목표 시각은 `clip_start + (현재 훈련시각 - 공개 메시지의 훈련시각)`을 clip_end로 제한한다. 지연 로딩/재접속은 최신 권한 스냅샷과 같은 식으로 현재 위치를 복구한다. 일시정지는 영상을 정지하고 재개는 같은 훈련시계에 맞춘다. 되돌림/과거 재생에서 해당 사건이 없으면 영상과 URL을 제거한다. 브라우저 자동재생 차단은 사람의 재생 버튼과 명확한 상태로 안내한다. 영상 자체의 촬영시각을 훈련시계로 주장하지 않는다.

실제 브라우저에서 수신 시각 기준 계산의 약0.8초 차이를 확인해, 서버가 elapsed와 clock_sampled_at을 같은 순간에 표본화하도록 바꿨다. 인증된 /api/v1/clock의3회 왕복 중 최소 지연 표본을 브라우저 performance.now()에 대응시키고30초/재접속 때 보정한다. 화면 렌더 지연이나 기관 PC의 절대시계 일치에 의존하지 않는다. 시간 API 오류/보정 전에는 수신시각 대안을 사용하며 일시정지/REPLAY는 보정과 무관하게 고정한다. 왕복 보정은 네트워크 비대칭·정체의 영향을 받으므로 실제 LAN과 기준 PC 오차는 기관 실증에서 다시 측정한다.

기본3D는 주 화면을 유지하고 별도 영상 패널에서 출처·기준일·상황/연출·객체ID·공개 범위·현재 사건 버전을 표시한다. 유출 시험·정지/재개/되돌림/재접속/과거 재생·실패 대안·AAR 출처/권리·두 엔진 실제 미디어 재생을 검증한다. 실제 영상·동의/익명화/기관 승인·실시간 중계는 제공된 것으로 가정하지 않는다.

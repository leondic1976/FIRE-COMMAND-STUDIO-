# 로컬 구현·검증 인계

2026-11-18 현재: [v0.2 웹서버·Windows 다운로드](https://github.com/leondic1976/FIRE-COMMAND-STUDIO-/releases/tag/v0.2.0)와 [공개 안내](https://leondic1976.github.io/FIRE-COMMAND-STUDIO-/)를 제공한다. 양쪽 JSON 설정·실제 설치 업그레이드/복구·두 엔진을 검증했다. 서버 설치/계정/HTTPS는 [웹서버 운영](WEB_DEPLOYMENT.md), 설정 파일 사용은 [사용자 매뉴얼](USER_MANUAL.md), 최신 증거는 [투트랙 수용](evidence/dual-track-20261118.json)을 따른다. 아래 표는 11월17일 원래 소스 검증의 시점 기록이다.

현재는 **로컬 합성자료 구현·자동검증을 마친 버전**이다. 이 문서는 로컬 합성자료 구현의 제공 범위와 기관 수용에 필요한 실제 확인을 구분한다. 기관 정규 출시/전문가 승인/실제 회의실 시범훈련을 완료했다는 문서가 아니다.

## 실행과 검토 경로

일반 Windows 사용자는 이제 [설치판](https://github.com/leondic1976/FIRE-COMMAND-STUDIO-/releases/tag/v0.2.0)을 사용할 수 있다. Python/Node 설치 없이 실행 창에서 연다. 단일 PC·공용화면·백업/제거 안내는 [Windows 배포](WINDOWS_DISTRIBUTION.md)를 따른다. 아래8010은 기존 소스 실행 경로다.

로컬 앱은 `http://127.0.0.1:8010`에서 실행한다. 다시 실행할 때는 README의 의존성 설치/웹 빌드 후 `python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8010 --workers 1`을 사용한다. 기본은 가명/합성 데모이며 실제 기관 명부·도면·키를 입력하는 운영 환경은 아니다. 자동시험용8011/8012 서버는 기관 배포용이 아니다.

1. 가상 진행자로 새 훈련을 만들고12단계에서 역할·보고선·근무/대체·임무 숙지부터 확인한다. 실제 구두 확인/기관 승인을 자동으로 채우는 기능은 제공하지 않는다.
2. 건물·지도·자원에서 가상 용도/지붕/지하·층 윤곽·내부 요소/주변 자원·인접동 거리/방위를 작성하고 저장/재조회한다. 가상 장면의 GLB/JSON/출처 묶음은 실제 자료와 구분한다.
3. 사건의 메시지·공개 범위·원자 상태 패치·분기를 확인하고 품질 검사/리허설/발행 뒤 실행본을 만든다. 진행자 미리보기·사유가 있는 연기/건너뛰기·되돌림·통제단 전환 이력을 확인한다.
4. 별도 공동화면에서 미래 사건/정답/개인평가/비공개 상태가 보이지 않는지 확인한다.3D/2D의 사건 상태 요약과 공개된 영상의 클립·훈련시계·출처를 확인한다.
5. 수신→인지→사실 확인→보고→결정→회신→종결과 대체 수락→숙지→구두 확인→인계→활성화 순서를 수행한다. 실제 수행자와 대리 입력자, 이전 담당자 귀속을 구분한다.
6. 관찰 근거→개선과제/책임 역할/목표일/재훈련→완료 증거→평가관 승인과 AAR/재생/내보내기를 확인한다. 상세 조작은 USER_MANUAL을 따른다.

실제 파일 입력은 승인 검사기/변환 호스트가 준비되기 전 격리를 유지한다. 합성 시험용 검사 응답을 운영 검사기로 바꾸거나 승인된 것으로 표시하지 않는다. 영상은 현재 승인 녹화 파일의 사건 동기 연계이며 실시간 중계 필요 여부는 질문 대기다.

## 기관에서 확인할 필수 잔여

- 법령/기관 편성·SOP/보고선·대체·통제단 전환을 확인할 실제 검수자와 승인된 자료 버전.
- 실제 자산/촬영·가공·공개 이용권과 정확도, 승인 AV/서명 갱신·격리 호스트/미디어 도구·보안/개인정보 검수.
- 공공 API 실키/기관 데이터셋·컬럼/최신성, 지도 공개 JS 키/도메인/약관. 키는 승인 서버 환경에 설정하며 Git/채팅/로그에 기입하지 않는다.
- 기준 PC/GPU·1080p 프로젝터·실제 LAN·진행1/참가 약10/평가1의 실제 일정과 관찰 결과.
- 운영 DB/TLS/기관 계정·필요 시 SSO/보유기간·접근/반출 정책과 실제 백업복구 리허설.

INSTITUTION_ACCEPTANCE는 이를 위한 **미실행 양식**이다. 실제 값/관찰/승인 참조가 제공되면 해당 버전/환경에서 시험하고 실패·보류도 남긴다. 필수 AC·전문가·실제 시범훈련 증거가 없는 현재는 기관 정규 출시를 보류한다. 원격 GitHub 게시·배포·다른 사람에게 메시지 발송은 수행하지 않았다.

# 운영·사용자 매뉴얼

## 진행자

기본 데모의 ‘훈련 진행자’를 선택한다. 실제 편성이 아니라 가명 10명과 7개 역할, 대체자 3명이 들어 있다. 새 훈련에서 물류창고·고층·지하 침수·복합재난을 선택할 수 있고 내용은 자유롭게 바꿀 수 있다.

제작 12단계에서 먼저 임무와 보고선을 정한다. 날짜/근무조와 참석 가능 여부·대체 순위를 확인한다. CSV/XLSX 가져오기는 오류와 결과를 미리 보여주며 ‘변경 저장’ 전에는 확정되지 않는다. 불러오기 열은 README 및 단계 화면을 참고한다.

가상 건물은 층수·층고·폭·깊이·위치·회전·외벽색·출입구를 편집한다. ‘지도에서 윤곽 작성’으로 빈 지점을 3번 이상 찍고 적용한다. 구역·도로·소화전·차량과 사건 상태 패치는 고급 JSON에서 고유 ID를 연결한다. 실제 자료가 없으면 가상/근사 표시를 유지한다.

기관이 공공자료 연결을 승인·설정한 경우 ‘훈련 대상물’ 단계의 ‘공공 기준자료 수집·검토’를 사용한다. 수집만으로 건물은 바뀌지 않는다. 출처·항목별 기준일·위치·단위·이용권을 확인하고 반영할 항목과 검토 메모를 남긴다. 용수시설의 현재 사용 가능 여부는 미확인이다. 건축물대장은 실내 도면이 아니며 반영 뒤 리허설·발행을 다시 확인한다. 상세 설정은 [공공자료 안내](PUBLIC_DATA.md)를 따른다.

‘건물·지도·자원’에서 GLB/PNG/JPEG와 제작자·기준일·이용범위를 입력한다. 검사 미설정이면 격리를 유지하므로 파일 표시/연결이 불가능하다. 검사 완료 뒤에도 미리보기에서 단위·위치·방향·층/객체 연결·공개범위를 확인하고 이용권 체크와 검토 메모를 남긴다. 사진은 참고 사진 또는 한 외벽의 색상맵이며 실내/다른 면/물성은 근사다. 변경/해제는 사유와 이력을 남기고 발행본은 잠긴다. IFC는 승인 오프라인 호스트에서 GLB로 변환한 뒤 변환 기록과 함께 입력한다. [자산 입력·제한](ASSET_PIPELINE.md)을 따른다.

사건에는 목표·발신자·수신 역할·발생 조건·공개 범위·후속 ID·종료 조건을 정한다. 예상행동은 비공개다. 원시 JavaScript/Python은 조건식으로 실행되지 않는다.

승인 녹화 영상은 ‘건물·지도·자원’의 자산 입력에서 MP4/WebM 파일과 원천·촬영/합성 기준일·이용범위를 등록한다. 기본 운영 설정은 AV/변환 승인 전 격리 상태다. 검사와 사람 검토를 거친 VIDEO 연결을 만든 뒤 ‘사건·메시지·분기’의 ‘검토 영상 연결’에서 같은 건물의 장면 객체와 클립 시작/종료 초를 지정하고 저장한다. STAFF/INTERNAL 영상은 참가자 사건에 연결할 수 없다. 픽셀·음성의 익명화는 자동 보증하지 않는다.

영상 패널은 해당 사건이 공개된 뒤에 나타나며 기본 음소거로 훈련시계에 맞춰 재생한다. 일시정지·재개·재접속에도 같은 사건 시각을 따르므로 개별 탐색 막대는 제공하지 않는다. 자동재생이 차단되면 ‘동기 영상 재생 허용’을 누른다. 전체화면에도 훈련 워터마크가 남는다. 되돌린 사건은 현재 화면에서 숨기되 과거 공개 시퀀스의 재생 이력에는 남는다. 촬영시각은 현재 현장이나 실제 중계로 해석하지 않는다. 검사/무결성/디코딩 오류가 나면 영상 오류 안내와3D·메시지로 훈련을 계속한다.

임무 숙지 메뉴에서 실제로 확인한 답안과 업무 설명을 대리 기록할 수 있다. 자동시험처럼 정답을 일괄 채우는 기능은 제공하지 않는다. 구두 확인은 참가자가 본인 보고선·핵심 업무·권한을 설명한 사실을 메모한다.

12단계에서 품질 검사·리허설·발행을 수행한다. 발행본은 잠기며 수정은 복제본에서 한다. 실행본을 만들고 상황판의 ‘훈련 시작’을 누른다. 사건은 미리보기와 변경 내용을 확인한 뒤 승인한다. 일시정지·되돌림·종료·통제단 전환에는 상태와 사유를 확인한다.

공용화면은 ‘공용화면’ 버튼의 전용 주소를 사용한다. 진행자 콘솔을 화면 공유하지 않는다. 별도 기기는 ‘공동 대형상황판’ 계정으로 접속한다. 그 경로의 응답에는 미래 사건·정답·개인평가가 포함되지 않는다.

후보 사건의 ‘공개 전 메시지·상태 변경 확인’에서 메시지와 객체/필드의 변경 전후를 대조한다. ‘연기’는 훈련시계 기준 시간과 사유를 남기며 그 시각 전 공개를 차단한다. ‘건너뛰기’는 현재 사건의 메시지/장면을 적용하지 않고 사유를 남겨 후속 후보로 이동한다. 이 미리보기와 사유는 진행자 비공개 영역이다.

상황판 위에서3D 영역 너비(넓은 화면)/높이를 키보드나 슬라이더로 조절하고 메시지를 상황판 안에서 고정할 수 있다. ‘화면 배치 원위치’는 기본 배치로 돌린다. 2D 대안 목록은 Home/End 키로 첫/마지막 정보를 실제 화면에 표시한다.

3D의 ‘장면 상태 요약’과2D 목록에서 현재 권한으로 받은 연기·화재·강우·바람·정전·자원 상태를 문장으로 확인한다. 수치는 훈련 연출 단계이며 실제 기상·피해 예측이 아니다. 복잡한 장면이 렌더링 예산을 넘으면3D 생성 전에2D로 전환하며 사건 메시지와 상태 목록은 유지한다.

‘건물·지도·자원’의 상세 편집에서는10개 용도의 가상 치수 제안, 지하층·지붕·창호·마감을 선택한다. 기존 사건과 구역은 유지하므로 층수를 줄였다면 참조를 점검한다. 층을 고른 뒤 ‘층 윤곽 그리기’로 평면도의 꼭짓점을 누르고 적용한다. 실·복도·계단·승강기·방화구획·피난통로·소방시설·위험물 구역·연결통로를 추가해 이름/위치/치수/방향을 정한다. 사건이 참조하는 요소는 그 참조를 수정하기 전 삭제할 수 없다.

선택 건물·구역 복제는 새 ID로 생성하며 원본 사건·승인 자산 연결을 복제하지 않는다. 인접동은 주건물 기준 거리/방위 또는 동서/남북 좌표로 배치한다. 주변 자원 편집에서는 가상 도로·주차장·용수·차량·집결지·의료자원·통제선의 위치/크기/초기 상태를 설정한다. 초기 상태를 바꾼 뒤 사건의 전후 관계와 리허설을 다시 점검한다. 출처 기반 참고시설은 공공자료 검토 메뉴에서 관리한다.

상황판에서 표시할 지상/지하층을 고르고 ‘내부 도식 절개’를 켜면 선택 층의 내부 모사 기하를 확인할 수 있다. 구조/피난 성능을 해석하는 도구는 아니다. 변경 저장 후 ‘가상 장면 GLB·JSON 내보내기’로 기하/장면/출처·해시/훈련 고지를 ZIP으로 보관한다. 실제/참조 자료나 승인 자산이 포함된 장면은 재배포 권리를 추정하지 않고 이 경로에서 제외한다. 초안 내보내기를 기관 승인본으로 취급하지 않는다.

## 참가자

먼저 접속해 진행자의 실행본 생성이 보이지 않으면 상단 ‘훈련 목록 새로고침’을 누르고 참여할 훈련을 선택한다. 계정을 전환하면 이전 계정의 화면·선택은 초기화된다.

‘훈련 실행본 선택’에는 현재 권한으로 접근할 수 있는 과거 실행본도 표시된다. 최근3개 목록에 없는 실행본을 선택해 기록·재생·AAR로 돌아갈 수 있다. 제작 중인 새 훈련에는 실행본 선택을 비워 둔다.

배정된 임무카드를 선택해 자료 버전·임무·보고선·권한 제한을 읽는다. 3개 문항과 ‘받을 정보·수행할 일·보고할 곳’ 설명을 제출하고 진행자 확인을 받는다. 카드는 사전 임무 자료이며 현재 교체 상태는 실행 상황판/인계 기록에서 확인한다.

상황판의 보고·조치 패널에서 본인 역할과 수신 메시지를 고른다. 수신→인지→사실 확인→보고·협조→결정·조치→회신→종결을 순서대로 기록한다. 실제 음성 토론은 진행자가 대리 입력해도 되며 수행자와 입력자를 구분한다.

대체 요청이 오면 수락하고 본인 카드·문항·설명을 다시 확인한다. 구두 확인·현재 상황·미확인 정보·미완료 임무·인수 확인 뒤 진행자가 활성화한다. 이전 담당자의 조치나 점수를 새 담당자에게 자동 이전하지 않는다.

‘개인 임무연습’은 혼자 시작할 수 있다. 역할과 난이도를 선택하면 다른 역할은 모의 동료로 표시한다. 다음 상황을 공개하고 본인 보고를 연습하면 사전 작성된 피드백을 받는다. 이 결과를 실전 지휘역량의 절대 점수로 사용하지 않는다.

## 평가관

공개·수신된 정보와 해당 사람의 행동 증거를 연결한다. 미수신·인계 이전 누락·정지 시간을 근거로 감점하지 않는다. 증거가 부족하면 미관찰로 남긴다. 구두 발언 전체가 자동 전사되었다고 가정하지 않는다.

개선과제는 관찰 증거·책임 역할·목표일·재훈련을 연결한다. 과제의 ‘완료 증거 기록’에서 실제 수행 근거와 검토 메모를 등록한다. 추가 관찰·과제 완료가 있으면 AAR 승인은 다시 받는다.

훈련 종료 후 승인 메모를 남기고 JSON·Markdown을 내보내거나 전체 AAR 인쇄 미리보기에서 PDF 저장을 선택한다. 실제 인쇄/브라우저 레이아웃 검수는 별도 필요하다.

## 문제와 복구

- 409 충돌: 다른 변경이 먼저 저장되었다. 최신 상태로 갱신해 확인한 뒤 다시 기록한다.
- 발행 차단: 표시된 G1~G8 오류를 수정한다. 숙지·역할 공백을 숨기기 위해 전체훈련으로 강행하지 않는다.
- 지도/로드뷰 오류: 로컬 도식을 유지한다. 미제공 지점·키/도메인·인터넷 승인 상태를 확인한다.
- 3D 미지원/성능 저하: 같은 사건 정보를 2D 대안으로 확인한다. 실사/공학 정확도로 과장하지 않는다.
- 재시작: 마지막 기록 상태로 복원·일시정지된다. 중단 구간 시간평가는 보류하고 상태·인계 확인 후 재개한다.
- 백업복구: 운영자가 서버를 중지하고 별도 새 파일의 해시·상태를 검증한다. 기존 DB를 덮어쓰지 않는다.

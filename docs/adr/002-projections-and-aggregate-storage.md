# ADR-002: 기관별 JSON 집계와 공개 투영

상태: 로컬 가상 MVP에 채택. 기관 운영 성능·보안 검수 전.

초기에는 Exercise와 Session 집계를 JSON으로 저장해 Pydantic 계약과 원자적 버전 갱신을 맞춘다. 기관 ID·종류·ID가 복합키이며, compare-and-swap 갱신·멱등키·별도 session_events·감사기록을 한 트랜잭션에 묶는다. 발행 시점 편성은 불변, 현재 편성은 별도 roster다.

원래 계획의 모든 정규화 테이블을 구현했다고 주장하지 않는다. 초기 규모의 일관성 검증에 집중하며, 장기간 대용량·검색·PostGIS·다중 노드가 필요하면 명시적 스키마 마이그레이션과 회귀 시험을 통해 분리한다. 최초 DB 스키마 v1 초기화와 SQLite 백업/새 파일 복구만 검증했다.

공개 화면의 보안 경계는 UI 숨김이 아니라 서버 투영이다. 메시지·미래 사건·예상행동·평가뿐 아니라 비공개 공간 상태도 필터링한다. WS는 최신 필터 스냅샷을 보내며, 재접속은 이력 보존 상태를 재구성한다. 다른 기관 ID는 항상 서버 조회 조건에 포함한다.

실제 기관 승인·SSO·정밀 자산·외부 공급자는 별도 검증 단계다. 기본 경로는 합성 데이터·AI OFF·외부 발신 없음·로컬 지도다.

2026-11-17 자산 단계에서 스키마2 `asset_blobs`를 추가했다. 격리 원본/정규화 바이트와 JSON 메타데이터를 같은 트랜잭션으로 기록하고 자산/현재 훈련/공용화면 권한을 확인한다. v1→2/기존 JSON 기본값·자산 포함 SQLite 백업/새 파일 복구를 검증했다. 앞의 v1 설명은 최초 결정의 기록이며 현재 버전/복구 절차는 ASSET_PIPELINE과 TEST_PLAN을 따른다. PostgreSQL/기관 저장소를 검증했다고 확대하지 않는다.

# 사건·공간·실시간 계약

실행 검증 기준은 `apps/api/domain.py`, 공개 JSON Schema는 `packages/domain-schemas/exercise.schema.json`, REST 계약은 같은 폴더의 `openapi.json`이다. `scripts/export_schemas.py`로 재생성한다.

## 대상물과 공간

`target_mode=REAL|VIRTUAL|VIRTUAL_ON_REAL_MAP`과 `scenario_factuality=SIMULATED|HISTORICAL`을 분리한다. 실제 대상물의 가상 사고와 실제 사고 기록을 혼용하지 않는다. 대상물·건물·층·구역·도로·소화전·차량은 고유 ID로 연결한다.

위치는 WGS84 중심 위·경도, 북쪽 보정각, 기준고를 저장한다. 장면의 X는 동쪽, Z는 남쪽, 거리는 m다. 회전은 Three.js의 양의 Y 회전과 맞추며 SVG에서는 반대 부호의 화면 회전을 적용한다. WGS84 투영은 소규모 지역의 근사식이며 실측·측량 정확도를 보증하지 않는다.

가상 건물은 층수·층고·폭·깊이·위치·회전·출입구·선택적 윤곽으로 재생성한다. 지하 침수 예제의 지하구역은 위치 주석이며 실제 지하 실내 복원 모델이 아니다.

상세 가상 생성기는 지하층 수·지붕/창호/마감·층별 윤곽과9종 내부 요소/주변 자원을 추가한다. 음수 지하층과0층 대지 참조를 구분하며 구버전은 기본값으로 읽는다. 동일한 ID/로컬 기하를3D·2D·사건·생성 GLB/JSON에서 참조한다. 계약/안전 예산과 검사·재사용 제한은 GENERATOR_CONTRACT를 따른다. 이 도식 생성으로 실제 실내 검증 상태를 바꾸지 않는다.

`asset_bindings`는 자산ID·고정 SHA256·건물/용도/공개범위·단위/회전/위치·노드별 층/구역 매핑·출처/검토시각을 가진다. `asset_reviews`의 전후 매핑과 검토자는 전용 서버 경로에서만 생성한다. 구버전 기본값은 둘 다 빈 목록이다. `asset-provenance.schema.json`은 multipart 업로드의 원천/이용범위·선택 IFC 변환 선언 계약이다. 바이너리/검사/공동화면 콘텐츠 권한과 DB2 마이그레이션은 ASSET_PIPELINE 참조.

## 사건

사건은 ID·제목·분류·목표·모의 발신자·수신 역할·공개 범위·우선순위·채널·본문·발생 조건·상태 패치·후속 ID·종료 조건·평가기준을 가진다. 예상행동은 진행자 데이터이며 공용/참가자 응답에 포함하지 않는다.

- MANUAL: 진행자 승인. 개인 연습은 본인 전용 제어 경로에서 승인한다.
- AT_TIME: 훈련시각 도달 시 후보. 발행본에서 명시적으로 허용한 항목만 서버 스케줄러가 자동 공개한다.
- ON_ACTION: 실제 저장된 조치 유형과 일치해야 한다.
- ON_CONDITION / ON_COMBINATION: 허용된 상태 필드와 eq/ne/gte/lte, AND/OR만 해석한다. 임의 코드 실행은 없다.

분기 검사에는 중복 ID·순환·없는 수신 역할·없는 구역·없는 후속 사건·도달 불가 사건·종료 불가·평가기준 누락이 포함된다. 리허설은 분기별 before/after 상태 충돌을 검사한다. 대규모 분기 조합은 실행 예산을 제한한다.

## 원자성·시퀀스·권한

모든 상태 변경은 `expected_state_version`과 `Idempotency-Key`를 요구한다. 버전이 다르면 409, 필수 버전/멱등키가 없으면 428이다. 같은 키의 같은 명령은 같은 결과를 반환하고, 같은 키에 다른 명령은 409다.

사건 공개는 메시지·실행 상태·장면 패치·불변 이벤트 저장을 한 DB 트랜잭션으로 처리한다. 패치의 현재 값이 before와 다르면 전체를 롤백한다. WS는 `session_id`, `event_seq`, `state_version`과 권한별 최신 스냅샷을 전송하며 재접속 때 최신 상태로 복원한다.

공용화면은 `/api/v1/board/sessions/{id}`, `/ws/v1/board/{id}`에서 항상 공개 투영을 사용한다. 비공개 메시지뿐 아니라 비공개 사건의 공간 상태도 공개 응답에서 제거한다. 오보 여부가 정답에 해당하면 참가자에게 미확인으로 표시한다.

브라우저는 같은 실행본의 낮은 state_version을 받은 순서와 관계없이 무시한다. 같은 버전에서는 오래된 clock_sampled_at이 최신 표본을 대체하지 않는다. 수신 시각은 상태 갱신 큐에 넣기 전에 캡처한다. 이 규칙은 서버의 기관/역할 투영과 별도로, 지연 REST 응답이 최신 WS 화면을 역행시키지 않게 한다. 실행본/계정 전환 시에는 기존 선택/권한 상태를 초기화한다.

## 재생·되돌림·복구

재생은 초기 장면에 선택 시퀀스까지의 패치를 적용한다. 조치 단계·관찰·개선과제·현재 편성도 해당 시점의 기록으로 제한한다. 되돌림은 일시정지와 사유를 요구하며 과거를 삭제하지 않고 역패치 이벤트를 추가한다. 이미 조치가 귀속된 사건은 지우지 않는다.

서버 재시작 때 진행 중 세션은 마지막 기록 시각으로 복원해 일시정지하고 복구 이벤트를 남긴다. 기록 이후 중단 구간은 시간평가에서 보류한다. 운영자는 상태와 인계를 확인한 뒤 재개한다.

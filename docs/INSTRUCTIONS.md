## 사전 질문 및 외부 의존성
- 기관 PostgreSQL/서버/실제 시범훈련 담당자 유무: 질문됨, 상세 답변 미제공. 계획 §20에 따라 로컬 가상 데모 구현 지속.
- 화면 검증: 과거 Chrome 연결 보류는 U-15의 백그라운드 Playwright 검증 지시로 해소됐다. 기존 Chrome 프로필을 사용하지 않고 로컬 합성 자료를 검증한다.
- 2026-11-17 공공 API 실키의 서버 환경 설정 가능 여부와 기관 SOP 검수자/약10명 시범훈련 담당자·일정을 질문했다. 실제 값/일정 답변은 아직 제공되지 않았다. 키를 채팅으로 요청하지 않으며 합성 HTTP 응답으로 구현/시험은 계속한다.
- 기관 SOP·명부·실제 모델·사진 이용권·외부지도 키·기준 PC·약 10명 회의실 실증은 제공되었다고 가정하지 않는다.
- 자산 검사기 선택(승인 로컬 clamd/다른 기관 검사기/미정)을 질문했으며 아직 답변되지 않았다. 운영 검사기/IFC 승인 플래그는 비활성, 합성 응답 주입으로 개발 검증만 진행한다.
- 전체 감사에서 영상 동기 요구가 미구현임을 확인했다. 남은시간 추정 누락을 정정하고 실시간 중계가 필수인지 질문했다. 답변 전 공통 기반인 승인 녹화 파일·사건 연계부터 구현하며 임의 URL/실제 지휘망에는 연결하지 않는다. 실제 AV/미디어 도구·호스트 승인 플래그는 비활성이다.

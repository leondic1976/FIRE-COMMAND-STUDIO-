# 보안·개인정보·자료 격리

## 구현된 통제

- DB 레코드와 이벤트는 기관 ID로 조회·변경한다. 다른 기관의 동일 ID는 404다. 공용·참가·참관·평가·진행 권한을 서버에서 구분한다.
- 로그인은 서버 측 세션 토큰을 HttpOnly·SameSite=Strict 쿠키로 전달하고, DB에는 토큰 SHA-256만 저장한다. 만료와 철회를 매 요청/WS 전송에 재확인한다.
- 운영 모드는 Secure 쿠키·HTTPS 설정을 요구하고 데모 로그인과 공개 API 문서를 비활성화한다. SSO는 아직 구현하지 않았다.
- 기관 계정 비밀번호는 무작위 salt와 버전이 포함된 scrypt(N=16384,r=8,p=5)로 저장한다. 이전 개발 해시는 성공 로그인 때 갱신한다. 비밀번호를 CLI 인수·출력에 넣지 않는다.
- 출처 허용 목록·교차 사이트 요청 차단·CSP·프레임 금지·MIME 추측 금지·센서 권한 차단을 적용한다. 외부 지도 출처는 명시적 승인 설정이 있을 때만 CSP에 추가한다.
- 실행 명령에 버전 충돌·멱등성을 적용하고 이력을 보존한다. 공개 DTO는 허용 필드 목록으로 구성한다. 비공개 공간 변화와 오보 정답도 분리한다.
- 실제 신고·출동·무전·지휘망 연결이나 외부 발신 기능은 없다. AI는 비활성이며 어떤 자료도 외부 모델로 보내지 않는다.

## 파일 입력

요청 본문은 Content-Length와 실제 스트림 모두 제한한다. 명부는 UTF-8 CSV/XLSX, 1MB·500개 데이터행이 기준이며 XLSX는 30열 이내다. 불러오기는 저장 전 미리보기로만 반환하고 오류가 있으면 UI에서 기존 편성을 대체하지 않는다.

XLSX는 필수 매니페스트, 파일 경로, 압축 해제 크기·비율·개수, 매크로·외부 링크, XML/.rels의 DTD·엔티티·외부 참조를 검사한다. defusedxml을 명시 의존성으로 유지한다. 손상·파서 예외·과대 입력은 422/413으로 반환한다.

GLB/PNG/JPEG는15MiB 제한으로 비공개 격리하고 원본 AV→제한 파서/정규화→정규화본 AV를 통과해야 미리보기/검토할 수 있다. 정적 core glTF2.0의 실제 버퍼/정점·계층/재질/이미지 예산·유한 좌표와 해시를 검사하며 외부 참조/확장 등은 거절한다. 사진은 제한 디코딩/재인코딩으로 EXIF/GPS 등을 제거한다. 기관/역할/공동화면별 콘텐츠 바이트를 서버에서 격리한다. 검사기 미설정/오류는 표시·연결을 차단하고 실제 승인/이용권·형상 검토를 자동 대체하지 않는다.

IFC는 서버와 분리한 승인 오프라인 CLI·고정 도구/전체 해시·Windows Job 자원 제한·현재 사용자 보호 임시 디렉터리로 처리한다. 영상은 AV 이후에만 고정 ffprobe/ffmpeg의 제한 프로세스·file/디먹서 허용목록·MOV 외부 참조 차단·메타데이터 제거/재인코딩을 수행한다. 공개 전/역할별 영상 메타데이터·파일 접근도 서버에서 제한한다. 네트워크 차단은 Job이 제공하지 않으며 별도 운영 검증이 필요하다. 실제 AV/호스트 승인은 미제공으로 기본 비활성이다. 영상 재생 UI/전체 통합은 개발 중이다. 구체적 설정/예산·DB2 복구는 ASSET_PIPELINE과 MEDIA_TIMELINE을 따른다.

임의 URL 가져오기·지도 타일 프록시·로드뷰 이미지 추출·텍스처 재가공 경로는 제공하지 않는다.

## 정규 운영의 미확인 사항

기관 SSO/계정정책·실제 자료 분류·보유기간·반출 승인·TLS 프록시·접근 로그 보호·PostgreSQL 권한·기관 백업복구·보안 담당자 심사는 제공되지 않았다. 이 저장소의 자동시험은 ASVS 전체 인증이나 정식 침투시험이 아니다. 실명·비공개 도면·실무 SOP를 데모·Git·시험 캡처에 넣지 않는다.

자유 서술 메시지에 사람이 비밀·정답을 직접 적어 공개하는 문제는 최종 제작자 검수가 필요하다. 자동 필터가 모든 문맥을 판단한다고 주장하지 않는다.

## 근거

검증 항목은 계획서의 OWASP ASVS 참고 범위를 따른다. 비밀번호 매개변수는 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)의 scrypt 대안 설정을 대조했다. 실제 기관 보안 적합성은 별도 승인 대상이다.

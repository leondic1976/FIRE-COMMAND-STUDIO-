## 출시 판단

계획서가 지정한 AC-01/04/06/07/09/13/19/23/25/29/32/35 중 일부는 실제 자료·화면·기관 검수가 남아 있다. 따라서 **기관 정규 훈련용 출시는 보류**한다. 로컬 합성 데모와 자동시험 성과를 실제 현장 효과·법적 적합성·실사 정확도로 확대 해석하지 않는다.

MVP 이후 확장은 실제 자료·키·승인·대상 PC·담당자가 확인된 순서로 이어간다. 외부 공공 API, 정밀 모델/사진, 영상/FDS, AI·SSO는 구현 상태와 운영 승인을 각각 구분한다.

개발 검증/AC30 보완: Python 의존성의 공개 권고 조회를 CI 설치 이후 단계에도 연결했다(IMP070·ci-audit-20261117.json). 로컬 조회37개/실패0/알려진 권고0과 YAML/읽기전용 권한을 확인했다. 원격 CI·기관 보안 검수는 미실행이며 기존 기능 시험의 범위를 확대하지 않는다.


U23~26 후속 배포 검증: 단일 운영 PC·구두 토론·대형 공개화면을 유지한 Windows 설치형0.1.0을 공개했다. Python 없는 PATH, 실제 설치·재실행·백업복원, 동일 버전 재설치/제거·13훈련 보존, 설치본 두 엔진 각7개와 지도 장애 각3개를 확인했다. AC29 공개 투영/AC32 기본 흐름/AC35 복구의 설치본 회귀이며 실제 기관 수용 증거는 대체하지 않는다. source bd78c0e와 [증거](evidence/windows-release-20261117.json), 자세한 [배포 계약](WINDOWS_DISTRIBUTION.md)을 따른다.

# 브이월드 연계 작업 계약

2026-11-18 U34: 미완료 작업 진행과 사용자 할 일 안내. 후속 사용자 지시로 공급자는 브이월드로 확정했다. 원본 plan.md와 AC38은 변경하지 않는다.

## 구현·검증 순서

1. V01 비공개 JSON 설정·숨김 키 입력 CLI·고정 HTTPS 공급자. 기본 비활성, 실키/서비스 등록/이용조건을 가정하지 않는다.
2. V02 인증된 진행자 주소/장소 검색. 고정 공식 검색 API만 호출하며 시간/크기/호출 제한과 일반 오류를 적용한다.
3. V03 브이월드3.0 SDK를 별도 sandbox 프레임에서 로드한다. 부모 세션·회의 기록·시나리오/화재·요구조자 배열은 프레임으로 보내지 않는다. 지도 좌표와 카메라 위치만 전달하고 카메라 행렬만 받는다.
4. V04 기존 자체 3D 화재/자원을 부모 화면에서 투명 오버레이한다. 지도 건물/사진을 추출·변환·저장하지 않는다. 설정 건물은 훈련 위치·층과 근사 가림 기준이며 실측 자료로 표시하지 않는다.
5. V05 A/B/C/D·설정 지휘대 시점·서버시계 사건/정지와 기존 공용 비공개 경계를 보존한다. provider 선택은 실행 스냅샷에 고정한다. 지도 원본은 상류 갱신될 수 있어 과거 실사 영상을 보존했다고 주장하지 않는다.
6. V06 키 없음/잘못된 출처/SDK·네트워크·WebGL 실패는 현재2D와 명시 상태로 복구한다. 가상 장면을 실제 브이월드 성공으로 표시하지 않는다.
7. V07 계약·권한/기관·비밀 누출·오류/제한·좌표·브라우저 합성 SDK 정상/실패와 기존 두 엔진 회귀·타입/빌드/추출을 실행한다. 합성 SDK 시험은 실제 서비스 성공과 구분한다.
8. V08 사용자 인증키·정확한 서비스 URL·첫 대상 건물의 실제 3D/외벽/지형·이용조건과 성능 확인 후 실환경 수용을 기록한다. 미제공 상태를 완료로 바꾸지 않는다.

## 공식 근거와 확인 한계

[국토교통부 API 등록](https://www.data.go.kr/data/3073144/openapi.do)은 WebGL3.0의 Cesium 기능·회원가입/인증키 발급과 대한민국 공간범위를 설명한다. [공식 예제 저장소](https://github.com/V-world/V-world_API_sample/tree/bb57af6e1a6e2e312634ac76dc7540e135ec10a0)의3.0 loader, vw.Map/start, ws3d.viewer, vw.ws3dInitCallBack, facility_build를 확인했다. 예제의 타인 키·모델은 복사/사용하지 않는다.

공식 포털 레퍼런스·약관 원문은 현재 조회 실패다. localhost/IP/포트 등록 허용·호출 한도·시설별 갱신/제외 범위·재사용권을 추정하지 않는다. 전국 공간범위는 모든 건물의 최신 실사/실내/정밀도를 보장하지 않는다. SDK 로고·출처는 유지하며 별도 캐시/텍스처 추출을 하지 않는다.

## 사용자가 준비할 것

- 브이월드 본인 계정으로 WebGL3D와 지도검색용 인증키를 신청한다. 현재 사용할 서비스 URL은 http://127.0.0.1:8090/이다. 정확한 등록 허용 방식과 약관은 발급 화면/운영자에게 확인한다.
- 키를 채팅/Git/문서/테스트에 넣지 않는다. 제공할 숨김 입력 명령으로 이 PC의 비공개 JSON에 설정한다. 브라우저 SDK 키는 동작 시 브라우저에 전달되므로 서비스 도메인을 제한해야 한다.
- 우선 검증할 공개 건물1곳의 주소·A 전면 방향과 외부 지도 서비스로 해당 좌표를 조회해도 되는 범위를 정한다. 비공개 시설 자료는 제공하지 않는다.
- 실제 운영이 이 PC+대형 화면이면 별도 호스팅 계약은 필요 없다. 인터넷 원격 운영이 필요하면 서버/도메인/DNS 담당을 지정한다.
- 기관 정규 수용에는 실제 AV·SOP/자료 정확도 검수·기준 PC/프로젝터·약10명 회의실 시범훈련을 별도로 준비한다.
